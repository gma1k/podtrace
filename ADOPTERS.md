# Adopters

Organizations and projects using podtrace. If you are running it, we would be
glad to add you.

## How to be listed

Open an issue with the
[adopters template](https://github.com/gma1k/podtrace/issues/new?template=adopters.yml)
and we will add the entry. Include your organization, how you use podtrace, and
optionally a public link. A private listing is fine too, say so in the issue and
we will record the use case without naming you.

Maturity stages used below: **Production**, **Pre-production**, **Development**,
**Conceptual**.

## Why we ask

Knowing which kernels, platforms, and workloads podtrace runs against directly
shapes what gets tested and what stays supported. Adoption data is the main
input into the compatibility matrix in
[docs/compatibility.md](docs/compatibility.md).
